# Sharon's Beauty Store

A simple multi-page e-commerce website for a fictional skincare and wellness shop. Built with plain HTML, CSS, and JavaScript.

## Pages

- `index.html` — Home page with hero, featured products, and brand story
- `products.html` — Product catalogue with Add to Cart interactions
- `about.html` — Business story, mission, and values
- `contact.html` — Contact form and phone/social details

## Assets and code

- `styles.css` contains the complete responsive design.
- `script.js` handles the mobile navigation, saved cart count, and contact form feedback.
- Product images are stored in `assets/`.

## Run locally

Open `index.html` in a browser. For the best development experience, use VS Code with the Live Server extension.

The store is a front-end demo: the cart count is saved in the browser, and the contact form shows a confirmation message without sending data to a server.
